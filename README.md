# 성어 뜻 맞히기 ver2 (304~337쪽)

고사성어 정답지 304~337쪽을 네 파트로 나눠 푸는 개인 학습용 페이지입니다.
어제 만든 ver1과는 별개이고, 진도도 따로 저장됩니다.

- 파트 1 — 304~312쪽 (80개)
- 파트 2 — 313~320쪽 (80개)
- 파트 3 — 321~325쪽 (66개)
- 파트 4 — 328~337쪽 (146개)

성어를 보고 뜻을 고르는 방식이며, 틀리면 한자 풀이·글자 그대로의 뜻·전체 뜻을 보여 줍니다.
파트마다 오답 노트가 따로 있어 그 파트에서 틀린 것만 다시 풀 수 있습니다.
기록은 기기 안(localStorage)에만 저장됩니다.
